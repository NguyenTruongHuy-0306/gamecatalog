# Dev Log — 2026-06-09

## Summary

Seven commits landed today covering forum restructuring, two new UX features, CI/CD fixes, and a full IGDB auto-sync integration.

---

## Commits

### `cf64075` — Link forum threads to games with per-game forum pages

- Added `gameId` (optional FK) and `@@index([gameId])` to `ForumThread` in Prisma schema
- Migration: `20260609000000_forum_game_link`
- `GET /api/forum/threads` now accepts `?gameId=` filter
- `POST /api/forum/threads` validates that the referenced game exists before creating the thread
- New page: `/games/[slug]/forum` — lists all threads for a specific game
- New page: `/games/[slug]/forum/new` — create a thread scoped to that game
- Game detail sidebar now shows a "Community Forum" card with thread count and links
- Thread detail breadcrumb: if thread has a linked game, shows `GameTitle / Forum / Thread`
- Added 13 tests in `src/app/api/forum/threads/route.test.ts`

---

### `46f1115` — Replace native confirm() with modal dialog for thread deletion

- Removed `window.confirm()` call in `ThreadDetailClient`
- Added `Dialog` component with Cancel and destructive Delete buttons
- Delete button shows "Deleting…" while the request is in flight

---

### `bc2a8be` — Add helpfulness voting to reviews

- Prisma schema: added `helpfulCount`, `notHelpfulCount`, `votes ReviewVote[]` to `Review`
- New `ReviewVote` model with composite PK `[userId, reviewId]`
- Migration: `20260609010000_review_votes`
- New route: `POST /api/games/[id]/reviews/[rid]/vote` — toggle-style (same value removes vote, different value switches it); returns 403 on own review
- `GET /api/games/[id]/reviews` now includes `helpfulCount`, `notHelpfulCount`, and `userVote` for authenticated users
- `ReviewCard`: optimistic UI update for thumbs-up / thumbs-down buttons; reverts on failure; disabled for unauthenticated users and review owners

---

### `49b04e1` — Only run prisma migrate deploy on production builds

- Changed `vercel-build` script in `package.json` to gate `prisma migrate deploy` behind `VERCEL_ENV === "production"`
- Prevents simultaneous advisory lock contention when multiple PR preview builds run concurrently

---

### `05d5185` — Remove redundant PR comment step from deploy workflow

- Removed "Comment preview URL on PR" step from `.github/workflows/deploy.yml` (Vercel's native integration already posts preview URLs)
- Fixed permission error caused by missing `pull-requests: write` scope

---

### `fb0bc09` — Scope forums to games only and add game forum directory

- Removed standalone community forum (`/forum`, `/forum/[category]`, `/forum/new` now redirect to `/games`)
- Made `gameId` required in `POST /api/forum/threads`
- `ThreadDetailClient` now accepts a `redirectPath` prop and redirects to the game forum after deletion
- New `/forum` page: lists all published games that have at least one active thread
- New `ForumDirectory` client component: instant search by game title + sort (Most Recent / Most Threads / A–Z)
- Restored "Forum" link in navbar (desktop + mobile)

---

### `b742bb5` — Add IGDB incremental sync with manual-edit protection

- Prisma schema: added `igdbId Int? @unique` and `lockedFields String[]` to `Game`; new `IgdbSyncState` singleton model
- Migration: `20260609020000_igdb_sync`
- `src/lib/igdb.ts`: Twitch OAuth client-credentials flow with DB-cached token; paginated Apicalypse queries respecting the 4 req/sec rate limit
- `src/lib/igdb-sync.ts`: maps IGDB fields → local schema, upserts genres, skips locked fields on update, creates new games as unpublished drafts
- `POST /api/admin/sync/igdb`: admin session or `CRON_SECRET` header; 5-minute `maxDuration`
- `GET /api/admin/sync/igdb`: returns last sync timestamp and pending-review count
- `vercel.json`: cron job fires every 6 hours
- Admin dashboard: `IgdbSyncPanel` shows last sync time, pending drafts count, Sync Now button with live result badges
- Game edit form: IGDB ID field + per-field lock toggles (title, slug, description, cover, year, developer, publisher, genres)
- Admin games table: blue "IGDB" badge on linked games

**Required env vars:** `IGDB_CLIENT_ID`, `IGDB_CLIENT_SECRET`, `CRON_SECRET`
