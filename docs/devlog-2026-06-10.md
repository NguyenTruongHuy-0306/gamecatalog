### `84bc7fc` — Fix LCP, TTFB, and reCAPTCHA script on flagged Speed Insights paths

Vercel Speed Insights flagged three specific paths needing improvement:

**`/` (home page)**
- Changed `export const dynamic = "force-dynamic"` → `export const revalidate = 3600`; page now caches at Vercel's CDN edge, TTFB drops from ~300 ms (DB hit every request) to ~10 ms (cache hit)
- Removed `ScrollReveal` wrapper from the `#1 RANKED` hero card — `.reveal` CSS sets `opacity: 0` so the card (the LCP element) was invisible until JS hydrated and IntersectionObserver fired; this was directly killing the LCP score
- Extracted session-dependent CTA section to `HomeCta` client component using `useSession()` so the page stays fully static; authenticated users see "Welcome back" without blocking the page cache
- Removed `auth()` call from page data fetching

**`/login`**
- Moved `RecaptchaProvider` out of the auth layout (was wrapping all auth pages: forgot-password, verify-email, reset-password, etc.) and scoped it to just the login page
- forgot-password, verify-email, and reset-password no longer load the reCAPTCHA script

**`/forum/new`**
- Added permanent CDN-level redirect (`/forum/new` → `/games`) in `next.config.ts`; previously a server-side `redirect()` in a page component requiring a full server round-trip

**New file:** `src/components/home/HomeCta.tsx`

### `4a7a198` — Add forum management to admin panel

New **Forum** section in the admin sidebar.

**`/admin/forum`** — Thread list
- Filter tabs: All Threads / 📌 Pinned / 🔒 Locked
- Category dropdown (all six forum categories)
- Free-text search by title, author username, or game title
- Sort by: Last Post, Title, Replies, Category (asc/desc toggle)
- Per-row actions: pin/unpin toggle, lock/unlock toggle, delete
- Bulk delete with select-all checkbox
- Reply count, category badge, game link displayed per row

**`/admin/forum/[id]`** — Thread detail
- Full original post body + all replies listed in order
- Pin/unpin, lock/unlock, delete thread from the header bar
- Delete individual replies inline
- Links to author user admin page and the public thread view

**New API routes:**
- `GET /api/admin/forum/threads` — paginated list with filter, category, and search params
- `GET /api/admin/forum/threads/[id]` — thread + all posts
- `PATCH /api/admin/forum/threads/[id]` — pin / unpin / lock / unlock / delete (soft)
- `PATCH /api/admin/forum/posts/[id]` — delete post (soft)

All routes protected with `requireAdmin()`.
